# 📱 GblackAI Mobile

> ⚙️ **Backend API**: [AbiHack2025_GblackAI](https://github.com/Gblack98/AbiHack2025_GblackAI) · [API Docs](https://gblackai-gblack98.vercel.app/docs)

A Flutter mobile app for AI-powered farm disease detection, connected to the **GblackAI** API (AbiHack 2025).

---

## 📸 Features

- Take a photo with the **camera** or pick one from the **gallery**
- 3 analysis types: **Plant/Pest**, **Satellite**, **Drone**
- Show detections with a colored **severity level**
- View **cropped zones** (Cloudinary crops)
- Detailed recommendations: biological, chemical, cultural
- **Light / dark theme** support

---

## ⚙️ Setup

### Requirements
- [Flutter SDK](https://docs.flutter.dev/get-started/install) ≥ 3.0
- Android Studio or VS Code with the Flutter extension
- An Android emulator or a real phone

### Steps

```bash
# 1. Clone the repo
git clone https://github.com/Gblack98/GblackAI-Mobile.git
cd GblackAI-Mobile

# 2. Install dependencies
flutter pub get

# 3. Set the API URL
# Edit lib/config.dart and update kApiBaseUrl
```

### Run the app

```bash
flutter run
```

### Build APK

```bash
flutter build apk --release
# APK location: build/app/outputs/flutter-apk/app-release.apk
```

---

## 🔧 Configuration

In `lib/config.dart`, set your API URL:

```dart
const String kApiBaseUrl = 'https://gblackai.vercel.app';
```

---

## 🔑 Android permissions

Declared in `AndroidManifest.xml`:
- `INTERNET` — API calls
- `CAMERA` — take photos
- `READ_MEDIA_IMAGES` / `READ_EXTERNAL_STORAGE` — gallery access

## 🔗 API

The app uses the `POST /api/v12/analyze` endpoint from [GblackAI API](https://github.com/Gblack98/AbiHack2025_GblackAI).
